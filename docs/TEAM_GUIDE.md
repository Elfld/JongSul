# 분실물 자동 분류 등록기 - 웹 프론트엔드

---

## 1. 프로젝트 개요

### 시스템 구성
```
[키오스크 장치] → [백엔드 API] ← [웹 프론트엔드]
     ↓                              ↑
  분실물 등록              사용자 조회/예약
```

### 웹 프론트엔드 역할
- 분실물 검색 및 조회
- 소유권 주장 (픽업 코드 발급)
- 예약 관리 (마이페이지)

## 3. 사용자 플로우

### 분실물 찾기
```
메인 페이지 접속
    ↓
분실물 목록 확인 (검색/태그 필터)
    ↓
카드 클릭 → 상세 모달
    ↓
"수령 예약하기" 클릭
    ↓
(미로그인 시) 로그인
    ↓
서약서 동의
    ↓
픽업 코드 발급 ✅
```

### 예약 관리
```
마이페이지 접속 (로그인 필요)
    ↓
예약 목록 확인 → 픽업 코드 확인
    ↓
(필요시) 예약 취소 (사유 선택)
```

## 6. 백엔드 연동

### 인증 방식
- **JWT Bearer Token**
- 로그인 → 토큰 발급 → 헤더로 전달
- `Authorization: Bearer {token}`

### 분실물 상태

| 상태 | 의미 | 웹에서 동작 |
|------|------|-------------|
| `stored` | 보관중 | 예약 가능 |
| `reserved` | 예약중 | 예약 불가 |
| `picked_up` | 수령완료 | 예약 불가 |

### 주요 데이터 흐름

**분실물 조회:**
```
GET /items/search?q=지갑&tags=1,2
→ 분실물 목록 (사진, 태그, 위치, 상태)
```

**소유권 주장:**
```
POST /items/{id}/claim (토큰 필요)
→ 픽업 코드 반환 (예: "A1B2C3")
```

**예약 취소:**
```
POST /items/me/{id}/cancel (토큰 필요)
body: { reason: "분실물이 아님" }
```

## 7. 주요 구현 기술

### API 프록시
```
브라우저 → Next.js API Routes → 백엔드
```
- CORS 문제 해결
- 11개 엔드포인트 구현

### 반응형 UI

| 화면 | 레이아웃 |
|------|----------|
| 모바일 | 카드 1열, 모달 바텀시트 |
| 태블릿 | 카드 2열 |
| 데스크톱 | 카드 3~4열, 모달 중앙 |

### UX 개선

| 기능 | 구현 |
|------|------|
| 검색 | 300ms Debounce |
| 필터 칩 | 드래그 스크롤 |
| 모달 닫기 | 뒤로가기/ESC |
| 이미지 실패 | Fallback 아이콘 |

## 9. 시연 시나리오

```
1. 메인 페이지 접속 → 분실물 목록 확인

2. 검색 및 필터 → 검색어 입력 / 태그 선택

3. 상세 확인 → 카드 클릭 → 모달 열림

4. 소유권 주장
   → "수령 예약하기" 클릭
   → 로그인 (미로그인 시)
   → 서약서 동의
   → 픽업 코드 발급

5. 마이페이지
   → 예약 목록 확인
   → 픽업 코드 확인
   → (필요시) 예약 취소
```
