# 웹사이트 조작 가이드

> 분실물 찾기 웹사이트 사용법

---

## 헤더

### 검색바
| 동작 | 설명 |
|------|------|
| 텍스트 입력 | 분실물 검색 (태그, 위치 기준) |
| 입력 후 대기 | 300ms 후 자동 검색 |
| X 버튼 | 검색어 초기화 |

**반응형 동작:**
- 데스크톱: 검색바 전체 표시
- 화면 축소: 검색바 너비 감소
- 모바일: 돋보기 버튼으로 변환 (클릭 시 검색창 열림)

### 로그인 버튼
| 상태 | 표시 | 클릭 시 |
|------|------|---------|
| 비로그인 | "로그인" | 로그인 페이지 이동 |
| 로그인 | "마이페이지" | 마이페이지 이동 |

---

## 태그 필터 (카테고리 칩)

| 동작 | 설명 |
|------|------|
| 칩 클릭 | 해당 태그 선택/해제 (토글) |
| 다중 선택 | 여러 태그 동시 선택 가능 (OR 조건) |
| 좌우 드래그 | 숨겨진 태그 보기 |
| "전체 해제" | 모든 필터 초기화 |

**선택 상태:**
- 미선택: 흰색 배경
- 선택됨: 하늘색 배경 + 체크 아이콘

---

## 분실물 카드

| 동작 | 설명 |
|------|------|
| 카드 클릭 | 상세 모달 열기 |
| 호버 | 카드 살짝 확대 + 그림자 |

**카드 표시 정보:**
- 사진 (없으면 기본 아이콘)
- 태그 목록
- 위치
- 등록일
- 상태 배지 (예약중/수령완료)

---

## 상세 모달

### 열기/닫기
| 동작 | 설명 |
|------|------|
| 카드 클릭 | 모달 열기 |
| X 버튼 | 모달 닫기 |
| 배경 클릭 | 모달 닫기 |
| ESC 키 | 모달 닫기 |
| 뒤로가기 | 모달 닫기 |

### 레이아웃
| 화면 | 형태 |
|------|------|
| 데스크톱 | 중앙 팝업 (이미지 2/3 + 정보 1/3) |
| 모바일 | 바텀시트 (이미지 위 + 정보 아래) |

### 예약 버튼
| 분실물 상태 | 버튼 상태 |
|-------------|-----------|
| 보관중 | 활성화 - "수령 예약하기" |
| 예약중 | 비활성화 - "예약중인 물품입니다" |
| 수령완료 | 비활성화 - "수령 완료된 물품입니다" |

---

## 소유권 주장 페이지

### 서약서
| 동작 | 설명 |
|------|------|
| 체크박스 | 서약서 동의 (필수) |
| "동의 및 수령하기" | 체크 시 활성화, 클릭 시 픽업 코드 발급 |
| "취소" | 메인 페이지로 이동 |

### 픽업 코드
- 발급 후 화면에 표시
- 키오스크에서 입력하여 수령

---

## 마이페이지

### 예약 목록
| 동작 | 설명 |
|------|------|
| 카드 클릭 | 예약 상세 모달 열기 |

**상태별 표시:**
| 상태 | 배지 색상 | 픽업 코드 |
|------|-----------|-----------|
| 수령 대기 | 파란색 | 표시됨 |
| 수령 완료 | 초록색 | 숨김 |
| 취소됨 | 회색 | 숨김 |

### 예약 상세 모달
| 동작 | 설명 |
|------|------|
| 닫기 | X 버튼, 배경 클릭, ESC |
| 예약 취소 | "예약 취소" 버튼 클릭 |

### 예약 취소
| 단계 | 설명 |
|------|------|
| 1 | "예약 취소" 클릭 |
| 2 | 취소 사유 선택 (라디오) |
| 3 | "기타" 선택 시 직접 입력 (100자) |
| 4 | "취소하기" 클릭 |

**취소 사유 옵션:**
- 분실물이 아닙니다
- 이미 찾았습니다
- 방문이 어렵습니다
- 기타 (직접 입력)

## 로그인 페이지

| 필드 | 입력 |
|------|------|
| 이메일 | 가입한 이메일 |
| 비밀번호 | 비밀번호 |

| 동작 | 설명 |
|------|------|
| "로그인" 버튼 | 로그인 시도 |
| "회원가입" 링크 | 회원가입 페이지 이동 |

---

## 회원가입 페이지

| 필드 | 입력 |
|------|------|
| 이메일 | 이메일 형식 |
| 비밀번호 | 8자 이상 |
| 비밀번호 확인 | 동일하게 입력 |

| 동작 | 설명 |
|------|------|
| "회원가입" 버튼 | 가입 시도 |
| "로그인" 링크 | 로그인 페이지 이동 |
