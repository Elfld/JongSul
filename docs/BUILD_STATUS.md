## 5. 알려진 버그 및 이슈

### 5.1 해결된 이슈
1. API URL 중복 /main 경로 (해결: 2025-11-20)
2. 검색 API trailing slash 500 에러 (해결: 2025-11-20)
3. 서약서 취소 버튼 동작 안 함 (해결: 2025-11-20)
4. 예약 취소 API 엔드포인트 오류 (해결: 2025-11-20)

### 5.2 현재 이슈

#### 5.2.1 마이페이지 스켈레톤 노출 (Medium)
- 증상: URL 직접 접근 시 0.5초 동안 스켈레톤 보임
- 원인: useEffect에서 인증 체크 (렌더링 후 실행)
- 영향: UX 저하 (보안 이슈 아님)
- 상태: 수정 예정

#### 5.2.2 localStorage 토큰 저장 (Medium)
- 증상: XSS 공격 시 토큰 탈취 가능
- 원인: httpOnly Cookie 미사용
- 영향: 보안 취약점
- 상태: 백엔드 변경 필요

#### 5.2.3 알림 설정 동기화 불가 (Low)
- 증상: 브라우저/기기별 설정 독립적
- 원인: localStorage만 사용
- 영향: UX 저하
- 상태: 백엔드 연동 필요

#### 5.2.4 취소된 예약 재예약 불가 (Unknown)
- 증상: 한 번 취소한 아이템은 재예약 안 됨
- 원인: 서버 측 이력 체크 (추정)
- 영향: 기능 제약
- 상태: 서버팀 확인 필요

### 5.3 개선 필요 사항

#### 5.3.1 폼 검증 강화 (Low)
- 현재: HTML5 기본 검증만
- 개선안: 클라이언트 JavaScript 검증 추가
  - 이메일 정규식
  - 비밀번호 강도 체크

- 개선안: 사용자 친화적 메시지
